##This project implements a custom user management system using ASP.NET Core MVC 6 and ASP.NET Core Identity. The system is designed to provide flexibility and control over user management logic, while still leveraging the robust features of Identity for authentication and authorization.

##Key Features
  Custom User Management Logic: The system allows you to implement your own logic for user registration, login, roles, and permissions, without being tightly coupled to the default Identity implementation.

  Role-Based Access Control (RBAC): Users can be assigned roles, and roles can be assigned permissions to control access to different parts of the application.

  Extensible Design: The system is designed to be easily extended to accommodate additional features or custom requirements.

  Secure Authentication: Built on top of ASP.NET Core Identity, the system ensures secure password hashing, token generation, and other security best practices.
